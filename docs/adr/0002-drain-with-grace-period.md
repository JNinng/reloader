# 排空采用宽限期而非引用计数

换下的旧资源经可配宽限期后关闭（`WithCloseDelay`，默认 30s，0 为立即），不做引用计数（`Acquire/Release` 或 `Do(func(T))` 回调式借用）。理由：引用计数忘释放即泄漏、API 面大，而宽限期以一行 timer 覆盖绝大多数热更场景；在途持有者拿到的旧资源在宽限期内仍可用。连带决策：当前资源以直接读取取用——`Current()` 返回 T，`Snapshot()`/`Generation()` 供资源与世代严格配对及单独读世代，均无借用仪式；Shutdown 立即关闭当前资源并提前触发所有未到期的排空 timer。
